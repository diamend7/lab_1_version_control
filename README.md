# To-Do List

Невеликий веб-застосунок «Список справ», який я зробив для лабораторної роботи № 1 з Git (версійний контроль). Основна мета роботи — навчитися працювати з репозиторієм, тому сам проєкт простий: HTML, CSS та трохи JavaScript без жодних бібліотек.

## Що вміє програма

- додавати нові задачі;
- відмічати задачі як виконані (галочка), виконані закреслюються;
- видаляти окремі задачі кнопкою ✕;
- фільтрувати список: усі / активні / виконані;
- видаляти одразу всі виконані задачі;
- показувати, скільки задач ще залишилось;
- зберігати список у `localStorage`, тому після перезавантаження сторінки задачі нікуди не зникають.

## Як запустити

Ставити нічого не треба, програма працює просто в браузері.

1. Склонувати репозиторій:
   ```bash
   git clone https://github.com/ВАШ_ЛОГІН/lab_1_version_control.git
   ```
2. Зайти в папку проєкту:
   ```bash
   cd lab_1_version_control
   ```
3. Відкрити файл `index.html` у будь-якому браузері (двічі клікнути по ньому).
